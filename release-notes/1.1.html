Halfpast 1.1

  • Working hours per place. Set each place's hours and working days (Sun–Thu in the Gulf, Mon–Fri elsewhere); the grid and the fairest hour follow them.
  • Holidays. Each place's public holidays, and days off you add, show on the grid; a proposed time on one is flagged.
  • Travel. When your Mac changes time zone, Halfpast asks whether to plan from where you are.
  • Updates. Halfpast now checks for new versions by itself.
